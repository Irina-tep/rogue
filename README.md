# Rogue-Like Game

Консольная roguelike-игра на языке Go с использованием библиотеки `goncurses`. Вдохновлена классической игрой **Rogue** (1980).

Игрок погружается в случайно генерируемое подземелье из 21 уровня, сражается с монстрами, собирает сокровища, использует предметы и пытается добраться до самого низа.

---

## 🎮 Основные правила игры

### Цель
Пройдите все **21 уровень** подземелья. На каждом уровне нужно найти **портал** (символ `%`), ведущий на следующий уровень. Последний уровень завершает игру победой.

### Уровни
- Каждый уровень состоит из **9 комнат**, соединённых **коридорами**.
- Комнаты и коридоры генерируются случайным образом — каждое прохождение уникально.
- В комнатах находятся **противники** и **предметы**.
- Первая комната — **стартовая**, в ней нет врагов.
- С каждым уровнем сложность растёт: враги становятся сильнее, полезных предметов — меньше.

### Персонаж
У персонажа есть **4 основные характеристики**:

| Характеристика | Описание |
|---|---|
| **HP (Здоровье)** | Текущее здоровье. Если падает до 0 — игра заканчивается. |
| **Max HP (Макс. здоровье)** | Максимальный запас здоровья. Восстанавливается едой. |
| **Dexterity (Ловкость)** | Влияет на вероятность попадания по врагу и уклонения от атак. |
| **Strength (Сила)** | Определяет базовый урон в ближнем бою. |

### Противники
В игре **5 типов врагов**, каждый со своим поведением:

| Враг | Символ | Особенности |
|---|---|---|
| **Zombie (Зомби)** | `Z` (зелёный) | Низкая ловкость, средняя сила, высокое HP. Может заразить, уменьшая макс. HP. |
| **Vampire (Вампир)** | `V` (красный) | Высокая ловкость. Первый удар по нему всегда промах. Крадёт макс. HP при атаке. |
| **Ghost (Призрак)** | `G` (белый) | Телепортируется по комнате. Может становиться невидимым. |
| **Ogre (Огр)** | `O` (жёлтый) | Ходит на 2 клетки. Огромная сила и HP. После атаки отдыхает 1 ход. |
| **Snake Mage (Змей-маг)** | `S` (белый) | Ходит по диагонали. Может усыпить игрока на 1 ход. |

### Предметы

| Тип | Символ | Действие |
|---|---|---|
| **Food (Еда)** | `*` | Восстанавливает HP. |
| **Elixir (Эликсир)** | `!` | Временно повышает ловкость или силу. |
| **Scroll (Свиток)** | `?` | Постоянно повышает ловкость, силу или макс. HP. |
| **Weapon (Оружие)** | `/` | Меняет формулу урона (например, `1d4`, `1d6`). |

- Предметы поднимаются **автомatically** при наступлении на них.
- В рюкзаке может храниться **до 9 предметов каждого типа**.
- Оружие при смене **выпадает на пол** рядом с игроком.

### Бой
- Пошаговый режим: каждое действие игрока запускает ход врагов.
- Атака происходит при перемещении **на клетку с врагом**.
- **Формула боя:**
  1. **Проверка попадания** — зависит от ловкости атакующего и цели.
  2. **Расчёт урона** — зависит от силы и оружия.
  3. **Применение урона** — если HP ≤ 0, цель погибает.
- За победу игрок получает **сокровища** (Treasure), влияющие на рейтинг.

### Туман войны
- Неизведанные комнаты и коридоры **не отображаются**.
- Просмотренные, но покинутые комнаты показывают только **стены**.
- В комнате, где находится игрок, видно **всё**: стены, пол, врагов, предметы.
- В коридорах видимость ограничена **прямой видимостью** (Ray Casting + алгоритм Брезенхэма).

## 🕹️ Управление

| Клавиша | Действие |
|---|---|
| `W` / `A` / `S` / `D` | Перемещение (вверх / влево / вниз / вправо) |
| `H` | Выбрать / сменить оружие (0 — убрать оружие, 1–9 — выбрать) |
| `J` | Использовать еду (1–9 — выбрать) |
| `K` | Использовать эликсир (1–9 — выбрать) |
| `E` | Использовать свиток (1–9 — выбрать) |
| `Q` | Выйти из игры (с сохранением) |

### Главное меню
| Клавиша | Действие |
|---|---|
| `1` | Продолжить последнее сохранение |
| `2` | Новая игра |
| `3` | Таблица лидеров |
| `Q` | Выход |

---

## 📊 Статистика и таблица лидеров
- После каждого прохождения (успешного или нет) статистика сохраняется.
- Таблица лидеров сортируется по **количеству собранных сокровищ**.
- В статистике фиксируются: достигнутый уровень, количество врагов, съеденной еды, выпитых эликсиров, прочитанных свитков, нанесённых и пропущенных ударов, пройденных клеток.

---

## 💾 Сохранение и загрузка
- Игра автоматически сохраняется при выходе (`Q`).
- В главном меню можно **продолжить последнее сохранение** (пункт 1).
- Сохранения хранятся в папке `saves/` в формате JSON.
- Восстанавливается **полное состояние**: позиция игрока, характеристики, рюкзак, враги, предметы, туман войны.

## 🚀 Запуск игры

### Требования
- **Go** версии 1.21 или выше
- Библиотека **goncurses** (зависит от `ncurses`)

### Установка зависимостей

#### Linux (Debian/Ubuntu)
```bash
sudo apt-get install libncurses-dev
```

#### macOS (Homebrew)
```bash
brew install ncurses
```

#### Windows
На Windows рекомендуется использовать **WSL** (подсистема Linux) или **Cygwin** с установленным `ncurses`.

### Сборка и запуск

```bash
# Перейти в директорию с исходным кодом
cd src

# Собрать проект
go build -o rogue-game .

# Запустить игру
./rogue-game
```

Или одной командой:
```bash
cd src && go run .
```

## 🛠️ Технический стек

- **Язык:** Go
- **Графика:** goncurses (обёртка над ncurses)
- **Сохранения:** JSON
- **Архитектура:** разделение на слои:
  - `domain` — игровая логика (персонаж, враги, предметы, уровни, бой)
  - `presentation` — рендеринг и управление (goncurses)
  - `datalayer` — сохранение и загрузка данных

## 📁 Структура проекта

```
├── src/
│   ├── main.go          # Точка входа, главный игровой цикл
│   ├── player.go        # Структура игрока и рюкзака
│   ├── enemy.go         # Типы врагов, их поведение и атаки
│   ├── object.go        # Предметы (еда, эликсиры, свитки, оружие)
│   ├── room.go          # Комнаты и их генерация
│   ├── level.go         # Уровни, тайлы, туман войны, видимость
│   ├── tunnel.go        # Коридоры и граф соединения комнат
│   ├── render.go        # Рендеринг (goncurses)
│   ├── controller.go    # Управление, ввод, бой, предметы
│   ├── data_layer.go    # Сохранение/загрузка, статистика, лидерборд
│   ├── helper.go        # Вспомогательные функции (генератор чисел)
│   ├── go.mod           # Модуль Go
│   └── go.sum           # Контрольные суммы зависимостей
├── saves/               # Папка с сохранениями (создаётся автоматически)
└── README.md            # Этот файл
```
